# python-Basics
### First Python Program for starting
```python
print("Hello, myself")
```
This code will print "Hello, myself"

### Variables in Python
Syntax for Variable Assignment:
```python
x = 5  # Assigning an integer value to the variable x
y = "Hello"  # Assigning a string value to the variable y
```

#### **Arithematic operation**
- `+` (Addition)
- `-` (Subtraction)
- `*` (Multiplication)
- `/` (Division)
- `//` (Floor Division)
- `%` (Modulus)
- `**` (Exponentiation)
